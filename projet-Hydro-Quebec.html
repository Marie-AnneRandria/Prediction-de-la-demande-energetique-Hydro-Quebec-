Gestion des valeurs aberrantes

Afin de gérer les valeurs aberrantes, l’utilisation de la méthode de la distance interquartile est idéal.

Référence: GitHub Documentation, https://essicolo.github.io/ecologie-mathematique-R/chapitre-outliers.html#valeurs-et-%C3%A9chantillons-aberrants-d%C3%A9finition-origines-m%C3%A9thodes-de-d%C3%A9tection-et-traitement

# Définition de la fonction calculant la distance interquartile
iqr_01 <- function(x, probs = c(.25, .75), mult = 1.5, na.rm = TRUE) {
  
  io <- rep(NA, length(x)) # vecteur vide qui consignera si la valeur est aberrante ou non
  limits <- quantile(x, probs = probs, na.rm = na.rm)
  
  offset <- mult * (limits[2] - limits[1]) # calculer la distance limite des quartiles
  
  io[x > (limits[2] + offset) | x < (limits[1] - offset)] <- 0 # si en-deça ou au-delà des limites
  io[x <= (limits[2] + offset) & x >= (limits[1] - offset)] <- 1 # si à l'intérieur des limites
  return(io)
}

Ajout des métriques standards à la prédiction de la demande énergétique

Afin de mieux capturer la consommation énergétique, nous allons mettre au point des métriques HDD et CDD. HDD mesure la demande de chauffage en fonction des jours où la température est inférieure à une valeur de référence. CDD représente la demande de climatisation lors des journées plus chaudes.

Référence: Leveraging HDD and CDD with Linear Regression for Enhancecd Energy Analysis in Python, https://www.linkedin.com/pulse/leveraging-hdd-cdd-linear-regression-enhanced-energy-analysis-kmetz-tzece/

Équations mathématiques:

\(HDD = T_{base} - T_{mean}\) si \(T_{base}\) est plus petit que \(T_{mean}\). \(HDD = 0\), si \(T_{mean}\) est plus grand que \(T_{base}\).

où: \(T_{base}\) est la température de référence pour les jours à haute température, en général 65°F(18°C). \(T_{mean}\) est la moyenne des températures.

\(CDD = T_{mean} - T_{base}\) si \(T_{mean}\) est plus grand que \(T_{base}\). \(HDD = 0\), si \(T_{mean}\) est plus petit que \(T_{base}\).

où: \(T_{base}\) est la température de référence pour les jours à basse température, en général 65°F(18°C). \(T_{mean}\) est la moyenne des températures.

Référence: https://mrcc.purdue.edu/CLIMATE/Station/Daily/degreeday_description.html
